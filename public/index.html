TikTok LIVE Chat Reader

Source: https://github.com/khanhlx6/TikTok-Chat-Reader
A chat reader for TikTok LIVE utilizing TikTok-Live-Connector and Socket.IO to forward the data to the client. More Tools available at TikFinity.

Generate Overlay URL
Chưa cấu hình backend riêng. Trang này đang dùng demo server tiktok-chat-reader.zerody.one, server này bắt buộc reCAPTCHA khoá theo domain riêng nên sẽ báo reCAPTCHA verification required. Hãy mở Server để nhập Backend URL tự host (không cần captcha) hoặc dán Overlay Token 24h.
Mẹo nhanh: mở zerody.one → nhập username bất kỳ → bấm Generate Overlay URL → giải captcha → copy URL tab mới dán vào ô Token. Để dùng lâu dài không cần captcha, deploy server.js lên Render (1-click) hoặc chạy npm i && npm start.
